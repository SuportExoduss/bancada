# PROMPT MESTRE PARA CLAUDE CODE

Você está trabalhando no projeto BANCADA.

Antes de fazer qualquer alteração:

1. Leia `CLAUDE.md`.
2. Leia `docs/11-decisions/DECISIONS.md`.
3. Leia `docs/02-architecture/ARCHITECTURE.md`.
4. Leia o documento específico da funcionalidade.
5. Leia `docs/07-development/DEFINITION_OF_DONE.md`.

Regras:

- Não invente decisões de produto.
- Não introduza backend externo.
- Não crie servidor próprio.
- Use Firebase.
- Use Emulator durante desenvolvimento.
- Preserve arquitetura modular.
- Não coloque chamadas Firebase diretamente em telas.
- Não avance para outra fase sem concluir a atual.
- Não reescreva código estável sem necessidade.
- Não considere uma tela pronta se a lógica, segurança e persistência não estiverem prontas.

Quando houver ambiguidade importante:

PARAR E PERGUNTAR.
